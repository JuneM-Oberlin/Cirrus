Weather App: a short personal project

While I am building this I want a simple, end-to-end example I can explain on a resume: a Java backend that fetches live data and a tiny frontend that displays it. I wrote a simple `WeatherData` model, a `WeatherService` that calls OpenWeatherMap, and a Spark-based `WeatherServer` that serves JSON to a small static UI in `public/`.

Tech: Java (Maven), Spark Java, OkHttp, Gson, static HTML/CSS/JS.

Why I made it: to practice HTTP networking, JSON parsing, and connecting a backend to a web UI—all in a single, readable repo I can point employers to.

Skills shown: backend HTTP clients, JSON mapping, small web servers, build tooling (Maven), and safe secret handling (env vars).

Solo project, maintained by me.
